## 카카오 공개 검색 결과

공식 기관 웹사이트의 이름/지역을 기대값으로 사용했습니다. docs/public-query-samples.json에 10개 입력과 근거 URL을 고정했습니다. 공급자 응답의 이름·ID·주소·좌표와 파생 지역 ID는 결과 파일에 저장하지 않았습니다. 정확 이름이 유일한 후보의 지역 일치 여부만 기록했습니다. 독립적인 장소 ID 정답이 없으므로 자동 확정 정확도를 주장하지 않습니다. 첫 샘플의 키워드 재조회에서 같은 장소 ID 재출현 여부도 확인했습니다. ID 단독 조회 API를 검증한 것은 아닙니다.

## 다음 실행에 필요한 외부 조건

1. 네이버 계정 로그인 및 Local 검색 권한/키. 가입·약관·과금 결정은 계정 소유자의 확인이 필요합니다.
2. 실제 Android/iOS 공유 원문과 기대 지점. 문서의 지도별 10개 제안은 아직 충족하지 않았습니다.
3. 문의 초안(provider-inquiries.md)의 제공사 답변 또는 현재 용도를 명시적으로 허용하는 공식 근거. 허용 기간에 맞춘 조정 후 저장 플래그를 활성화합니다.
4. 호스팅 계정·대상 프로젝트·도메인/운영 예산. 현재 로컬 검증을 외부 배포 완료로 표시하지 않습니다.

추가 실제 링크 검사: 공식 기관의 네이버 지도 단축 링크와 비지도 폼 링크 2개 검증 통과. 선택 장소가 포함된 `/p/search/검색어/place/ID` 형식의 오분류를 수정했습니다. `scripts/verify-public-links.cjs`와 `docs/public-link-results.json`으로 재현할 수 있습니다. 모바일 OS 공유 샘플로 집계하지 않습니다.

## 결제 금지 지시 반영

사용자 지시에 따라 결제수단 등록·유료 서비스 신청·유료 서버 생성은 진행하지 않습니다. 네이버는 현재 계정의 결제수단 미등록 제한 때문에 보류하며 반복적인 등록 요청을 하지 않습니다. 외부 배포 대신 `npm run start:local`로 로컬 API와 Swagger를 실행할 수 있습니다. 기존 DB와 별도인 data/local을 사용하고 비밀키를 자동 생성·보존합니다. 카카오 조회를 기본 공급자로 선택하지만 장소/지역 저장 정책 플래그는 false를 강제합니다. 일반 장소 검색·자동 저장 기능이 활성화됐다는 의미는 아닙니다. 공급자 문의는 아직 미전송이며 승인 여부가 명확해질 때 전송합니다.
